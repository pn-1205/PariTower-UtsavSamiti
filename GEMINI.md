# Project Policies & Rules for Pari Tower Utsav Samiti

## Git Push & Deployment Policy
- **DO NOT automatically run `git push` or deploy.**
- Never push changes to Git / GitHub or trigger production deployments automatically after a coding session.
- **Always ask for user confirmation first**: At the end of every coding session or task, explicitly ask the user:
  > *"Should the update be pushed to Git and deployed to production now?"*
- Only execute `git push` or trigger deployment if the user explicitly confirms (e.g. "yes", "push it", "go ahead").
- This ensures the user can queue multiple fixes, test locally or review diffs in a single batch before updating the remote repository.

## Society Ledger & Donation Guidelines
- Contributions/Donations are general for the entire society festival fund (`General Utsav Fund`).
- Expenses are event/festival-specific (e.g., Ganeshotsav, Navratri, Diwali).
- All online UPI contributions are logged with status `PENDING_VERIFICATION` and reconciled by committee custodians.
